💡 The Two-Minute Explanation for Sir

To ensure scientific fairness and eliminate bias, our benchmark evaluates two distinct tiers of web security:

Tier 1: Classical Web Flaws (Where All Tools Agree)

Standard syntax and injection bugs like SQL Injection, Reflected XSS, and Information Disclosure. Both Burp Suite, Acunetix, and AegisAI detect 100% (4/4) of these bugs.

Tier 2: Business Logic & Authorization Flaws (The BOLA Blindspot)

Modern access-control bugs like Broken Object Level Authorization (BOLA / IDOR). Because the server returns a valid HTTP 200 OK, Burp Suite and Acunetix detect 0% (0/10), while AegisAI detects 100% (10/10).

🏨 The "Hotel Keycard" Analogy for Sir: Imagine a hotel where a guest from Room 101 tries to enter Room 102.
• If someone picks the lock with a crowbar (SQLi / XSS): Burp Suite, Acunetix, and AegisAI all hear the noise and catch the attacker immediately (Tier 1).
• If Room 101's keycard smoothly opens Room 102 (BOLA): Traditional scanners hear no alarm and assume the guest is in their own room. AegisAI tracks both guests, detects the unauthorized room entry, and fixes the keycard permissions in GitHub (Tier 2).
